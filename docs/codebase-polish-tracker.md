# Codebase Polish Tracker

Started: 2026-05-31

## Scope

- Pass type: bug fix, styling polish, type-safety, accessibility, and small
  correctness issues discovered during a top-to-bottom scan.
- Included: `src/app`, `src/components`, `src/hooks`, `src/store`, `src/lib`,
  `src/types`, root config files, and docs.
- Excluded: generated folders, dependencies, build output, and binary image
  assets in `public`.
- Constraints: no new features, no backend/auth/payments, no analytics, no new
  dependencies unless explicitly justified, and no speculative refactors.

## Success Criteria

- Every included area is scanned and marked below.
- Any code changes are surgical and directly tied to an observed issue.
- Verification runs at least `npm run lint` and `npm run typecheck`; run
  `npm run build` if the change size warrants it.

## Findings And Fixes

- Quick styles were implemented but not reachable from the editor settings UI.
  Mounted `BeautifyPresetBar` in the Style section.
- Landing navigation linked to `#workflow`, but the workflow section was not
  rendered. Mounted the existing workflow section and CTA section on the home
  page.
- Landing hero/example images used raw `<img>` tags and triggered Next lint
  warnings. Swapped public/remote landing assets to `next/image` and configured
  the remote Unsplash host.
- Several Tailwind utilities used values that are not generated by default
  (`duration-350`, `duration-250`, `h-4.5`, `text-slate-650`, etc.). Replaced
  them with nearby valid utilities.
- Text letter spacing allowed negative values in editor defaults and the Open
  Graph image. Kept the default at `0` and constrained the UI minimum to `0`.
- CTA section had unused heavy animated decorative layers once mounted. Removed
  them and kept the CTA focused on the actual action.
